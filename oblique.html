标志 / 字体 / 海报 / 视觉规范

不以咖啡或酒作为唯一的识别符号，而是以「阈限」为概念起点，探索日与夜、饮品业态与空间体验之间的视觉关系。

01  /  PROJECT BACKGROUND  /  项目背景

从日咖夜酒的复合业态出发。

OBLIQUE 是一个围绕「日咖夜酒」展开的毕业设计概念项目。

OBSERVATION  /  观察

具象品类符号

部分咖啡馆与酒吧以咖啡杯、咖啡豆或酒杯作为标志，能够直接传达业态，也可能带来相似的视觉印象。

QUESTION  /  问题

如何建立差异

当品牌同时关联咖啡与酒，单一饮品符号难以承载日与夜之间的转换关系。

AIM  /  目标

探索概念表达

跳出对单一品类符号的依赖，以更具概念性的方式表达日夜、饮品业态与空间体验。

02  /  CORE CONCEPT

阈限：处于转换之间

「阈限」指向日与夜、咖啡与酒之间的状态转换，也关联空间体验从一种状态进入另一种状态的过程。

让转换成为视觉线索。

设计尝试将介于两种状态之间的体验转化为视觉语言，使品牌标志不仅承担识别功能，也成为表达品牌概念的载体。

CONCEPT RESEARCH  /  概念研究

Liminal Archive

虚构的概念视觉档案，用于呈现项目中的研究与展示内容；不代表真实品牌运营、事件或商业事实。

03  /  DESIGN STRATEGY  /  设计策略

从概念到系统

以「阈限」为线索，将抽象概念转化为可识别并可延展的视觉表达。

01  /  BEYOND CATEGORY

跳出品类符号

不直接依赖咖啡杯、咖啡豆或酒杯等常见图形，从品牌概念本身寻找更抽象的视觉表达。

02  /  TRANSLATE

将阈限转化为视觉

围绕边界与过渡的关系展开标志设计，以简洁的几何构成表达状态之间的连接与变化。

03  /  SYSTEM

建立统一系统

以品牌标志为核心，延展至字体、海报、标志延展和品牌视觉规范，形成相互关联的视觉表达。

04  /  LOGO DESIGN  /  标志设计

在边界与过渡之间

品牌标志是 OBLIQUE 视觉系统的核心，也是将「阈限」概念转化为视觉语言的起点。

在几何边界中引入方向。

经过多轮草图推敲与方案比对，最终标志由两条线构成：一条宽 115 mm、高 2 mm 的长横线，以及一条宽 2 mm、高 20 mm 的短斜线。两条线居中相交，形成近似几何加号的简洁结构；短线向左倾斜 30°，在克制的几何关系中引入方向与变化。

长横线被定义为「地平线」，象征日常世界中稳定而清晰的边界；倾斜短线代表从一种状态向另一种状态的过渡。两线相交，将边界、转换与中间状态凝练为简洁符号。

COLOR  /  #CE201E

理性结构与感性温度

红色兼具警示感与生命力，联想到地平线上的落日余晖，也呼应微醺时刻脸颊泛起的绯红，为几何结构注入感性温度。

05  /  TYPE & VISUAL GUIDELINES

从标志到视觉系统

以品牌标志为视觉识别的起点，展开字体设计与组合关系，并通过品牌视觉规范梳理整体视觉表达。

本节依据现有字标与规范展示素材呈现识别系统；未补写未确认的字体名称、字形方法或网格参数。

ASSET TO ADD  /  待补充素材

字体设计与组合展示

如有独立字体设计稿或中英文文字与标志组合页面，可在此补充；当前仅展示已确认的字标与品牌组合规范素材。

06  /  POSTER & EXTENSION

视觉语言的延伸

通过海报与标志延展，观察核心视觉元素在不同画面中的表达。

07  /  SUMMARY  /  项目总结

让概念成为识别

OBLIQUE 从日咖夜酒的复合业态出发，以「阈限」为概念线索，将边界与过渡转化为品牌标志，并进一步延展至字体、海报与品牌视觉规范。项目尝试探索如何将抽象概念转化为具有识别性与延展性的视觉表达。
